## 构建与依赖边界

- Taro 新 NutUI React 的组件位于 `dist/es/packages`，Babel 按需加载改用该目录
  和小写组件名称。Taro 的旧 webpackbar 会修改父类 ProgressPlugin 的选项，
  被新 Webpack 的校验拒绝；两个示例使用原生 ProgressPlugin。
- NutUI 缺少 React 类型 peer，pnpm 会解析到其它示例的 React 19 类型。
  通过 packageExtensions 补齐 optional peer，将声明绑定到 Taro 的 React 18。
- Panda 2 PostCSS 插件只处理 `.css` 输入。Wevu 和 Uni 通过脚本导入独立 CSS，
  保证不会将 SFC style 虚拟输入误判而跳过样式生成。
- Uni 的 resolver 保留 symlink，CVA 的传递依赖无法从虚拟包路径解析。
  `clsx` 因此保留为显式依赖，不开启全局 hoist，也不改变框架 resolver。
- 五个示例的 Panda plugin 在同步 `codegen:prepare` hook 中转换生成 artifacts，覆盖
  codegen 及 PostCSS 触发的 runtime 再生成；开发和构建先 prepare 再 codegen。
- 不设全局 Vite 或 PostCSS major override。Taro、Uni 和 Web 示例各自拥有
  不同编译器批次。发布包的 ESM/CJS、PostCSS 入口和两个 CLI 名称保留。
- 移除未使用的 Jest、Taro test utils、Ramda、ts-node、cross-env、旧 Babel
  类型包，以及停用的 Taro / React Tailwind 配置。Uni 保留实际使用的 v4 对比。

## 锁文件与安装策略

共享锁文件更新到当前范围内的稳定版本。只为明确可兼容的安全修复设置窄范围
override：Jimp 的 jpeg-js、tinypool 2.1.0，以及上游固定旧版本的 Babel 7、
message-resolver、body-parser、lodash、lodash-es、PostCSS 8、qs、source-map-js、ws。
现有 selector parser override 保留。

NutUI 将文档上传 CLI `codesandbox` 误列为运行依赖；检查发布组件无任何引用，
通过父包限定 override 移除其依赖树。NutUI 的统计脚本和 Taro CLI 下载可选
性能插件的 postinstall 显式关闭，不需要这些脚本完成示例构建。

安装仍报告以下 upstream peer 边界；不全局忽略 peer 校验：

| 依赖链                                   | 当前限制与处理                                                               |
| ---------------------------------------- | ---------------------------------------------------------------------------- |
| repoctl 内部 pnpm 工具                   | logger 1100 与部分工具的 1001 peer 不同，repo 命令实际验证                   |
| Taro framework 的 Vite peer              | 要求 Vite 4，当前工作区提供 8；两个示例使用 Webpack，不调用 Taro Vite runner |
| Taro Webpack runner / loader / prebundle | 固定 Webpack 5.91.0 peer；保留 5.111.1，经实际构建验证并修复进度插件         |
| devframe                                 | agentic 1.1 peer 与实际 1.2.3 不同；微信原生构建和测试不启用 Web DevFrame    |
| tsconfck                                 | TypeScript 5 peer；当前 TypeScript 6 已验证 prepare、codegen 与类型检查      |

这些 peer 提示不代表其它编译路径已验证；新增平台应按对应框架验证。
doctor 的模板修改/删除提示来自精简生成模板，快照和 provenance 保留以支持
后续升级比较。selector-parser override 的锁文件证明限制由 frozen install 验证。

## 生成期插件迁移后的调整

Uni-app 的 Tailwind 对比功能由 `WeappTailwindcss` 独立生成。移除直接依赖和
重复注册的 `@tailwindcss/postcss`；Tailwind 的绝对 `cssEntries` 与 Panda 虚拟
CSS 入口分开，保留两套 runtime/selector 契约。见
[插件迁移指南](./panda-plugin-migration.md)。

v2 同时移除文件补丁与配置/CLI 兼容代码，删除适配包的直接依赖
