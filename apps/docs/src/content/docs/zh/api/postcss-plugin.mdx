## postcssPlugin(options)

```ts
import postcssPlugin from 'weapp-pandacss/postcss'
import type { IPostcssPluginOptions } from 'weapp-pandacss'

const plugin = postcssPlugin({ target: 'weapp' })
```

工厂接受可选的 `IPostcssPluginOptions` 对象，返回 PostCSS 插件。主包根入口以 `postcssPlugin` 导出相同工厂。`postcssPlugin()` 与 `postcssPlugin({})` 都使用下列默认值。

```ts
declare function postcssPlugin(options?: IPostcssPluginOptions): import('postcss').Plugin
```

```js
const postcssPlugin = require('weapp-pandacss/postcss')
const plugin = postcssPlugin({ target: 'weapp' })
```

独立 PostCSS 配置采用 `postcss-import → Panda → adapter → 按需单位转换`。Ordered 编译前必须完整展开导入图和 CSS nesting。Adapter 不读取导入文件，残留普通、带 layer 或远程 import 都会失败。流水线见[配置指南](/zh/postcss/)。

## 完整参数

所有字段可选。嵌套对象继承未填写字段的默认值；替换数组会覆盖默认数组，而非追加元素。

| 字段 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `target` | `'weapp' \| 'web'` | `'weapp'` | 选择平台 CSS 行为，两种目标的 class 名称一致 |
| `disabled` | `boolean` | `false` | 跳过全部转换，包括命名与标记 |
| `cascadeLayers.mode` | `'ordered' \| 'legacy'` | `'ordered'`，传入旧参数时可变为 legacy | 选择小程序 layer 编译方式 |
| `cascadeLayers.onConflict` | `'warning' \| 'error'` | `'warning'` | ordered layer 兼容诊断的严重级别 |
| `selectorReplacement.root` | `string \| string[]` | `'page'` | 替换小程序 CSS 的 `:root` 与 `:host` |
| `selectorReplacement.universal` | `string \| string[]` | `['view', 'text']` | 展开小程序 CSS 的 `*` |
| `selectorReplacement.cascadeLayers` | `string` | `'n'` | legacy 保留否定占位时使用的替换标签 |
| `removeNegationPseudoClass` | `boolean` | `true` | legacy 删除生成的 `:not(#\#)` 占位 |
| `cascadeLayersPluginOptions` | 对象，字段见下文 | `{}` | 透传给 legacy csstools layer 插件 |
| `isPseudoClassPluginOptions` | 对象，字段见下文 | `{}` | 小程序模式透传给 csstools `:is()` 转换 |

需要多个 root 或通配替换标签时使用数组：

```ts
const options: IPostcssPluginOptions = {
  selectorReplacement: {
    root: ['page', 'body'],
    universal: ['view', 'text', 'button'],
  },
}
```

按目标平台实际使用的组件选择替换标签。这只转换 selector 语法，不会设置原生组件的样式权限或 style isolation。

## csstools 参数

### cascadeLayersPluginOptions

仅用于 `mode: 'legacy'`。适配器默认传 `{}`，安装的 `@csstools/postcss-cascade-layers` 提供下列默认值。

| 字段 | 类型 | 上游默认值 | 含义 |
| --- | --- | --- | --- |
| `onRevertLayerKeyword` | `'warn' \| false` | `'warn'` | 对 `revert-layer` 处理发出警告 |
| `onConditionalRulesChangingLayerOrder` | `'warn' \| false` | `'warn'` | 条件规则可能改变 layer 顺序时警告 |
| `onImportLayerRule` | `'warn' \| false` | `'warn'` | 对带 layer 的导入发出警告 |

这些开关控制 legacy 警告，不会让不受支持的输入等同于原生 layer。Ordered 模式使用自身的诊断与硬错误。

### isPseudoClassPluginOptions

小程序的两种 layer 模式均适用；Web 保留原始 `:is()`。

| 字段 | 类型 | 上游默认值 | 含义 |
| --- | --- | --- | --- |
| `preserve` | `boolean` | `false` | 启用时同时保留原始写法与转换产物 |
| `onComplexSelector` | `'warning'` | 未设置 | 对 `:is()` 内复杂 selector 启用警告 |
| `onPseudoElement` | `'warning'` | 未设置 | 对 `:is()` 内伪元素启用警告 |
| `specificityMatchingName` | `string` | `'does-not-exist'` | 调整 specificity 时使用的 selector 名称 |

Legacy layer 开关使用 `'warn'`，`:is()` 开关使用 `'warning'`。这些类型来自安装的 csstools 插件，不由 `weapp-pandacss` 单独导出。

## 目标行为

| 转换 | `weapp` | `web` |
| --- | --- | --- |
| Portable class selector 编码 | 是 | 是 |
| Portable CSS 标记 | 是 | 是 |
| ASCII CSS 变量校验 | 是 | 否 |
| `:root` / `:host` / `*` 替换 | 是 | 否 |
| `:where()` 展开与 `:is()` 处理 | 是 | 否 |
| Layer 展平 | ordered 或 legacy | 保留原生 layer |

小程序的 `:where()` 展开为普通 selector，因此不保留其原生零权重语义。前一个 selector node 不是 class 时，转换器还会把 `~` 改成 `+`，例如 `* ~ *` 和 `.peer:hover ~ .target`；单纯 `.peer ~ .target` 保留 `~`。Peer 与状态 selector 应在真实目标上验证，语法适配不等于完整 Web selector polyfill。

`disabled: true` 时不改变 CSS，已编码的 runtime 名称可能无法匹配原始 selector。仅用于无需适配的样式，或已有其他流程负责配套命名的情况。

## Ordered 与 legacy 选择

默认 ordered，通过固定的 `@weapp-tailwindcss/css-compat@0.1.1` 内核编译 layer，兼容适配层保留既有选项和诊断文本前缀。按层顺序编译且不制造 specificity 占位。未指定模式时，显式传入任意下列字段会选择 legacy：

- `removeNegationPseudoClass`，包括 `true`。
- `selectorReplacement.cascadeLayers`，包括 `'n'`。
- `cascadeLayersPluginOptions`，包括 `{}`。

```ts
postcssPlugin({ cascadeLayers: { mode: 'ordered', onConflict: 'error' } })

postcssPlugin({
  cascadeLayers: { mode: 'legacy' },
  removeNegationPseudoClass: false,
  selectorReplacement: { cascadeLayers: 'n' },
})
```

Legacy 继续使用 `@csstools/postcss-cascade-layers`，不调用共享包的 `/legacy` 入口。Legacy 中，`removeNegationPseudoClass: true` 删除生成的 `:not(#\#)`；false 时将其内部 selector 替换为配置标签，默认得到 `:not(n)`。业务手写的 `:not(...)` 保留。

显式 `mode: 'ordered'` 与任意旧字段混用会报配置错误。工厂解析参数时就执行此检查，发生在 `disabled` 或 Web 跳过转换之前。删除旧字段或选择 legacy。`cascadeLayers.onConflict` 仅用于 ordered 模式。

## Layer 顺序与诊断

Ordered 按首次声明注册 layer。普通声明按层顺序输出，未分层规则在后；重要声明按层逆序输出，未分层重要声明在前。支持嵌套、点分路径、匿名与重复 layer，保留同层源码顺序。

WXSS selector 权重仍优先于输出顺序。编译器保守地报告潜在差异，警告不代表 selector 一定命中同一元素。

| 结构化 code | 兼容文本前缀 | 触发与处理 |
| --- | --- | --- |
| `LAYER_SPECIFICITY` | `WP_LAYER_SPECIFICITY` | 低优先层有更高权重的 selector，属性可能重叠；调整权重并检查实际匹配规则 |
| `LAYER_CONDITIONAL_ORDER` | `WP_LAYER_CONDITIONAL_ORDER` | 条件内首次注册 layer；先在条件外声明完整命名层顺序 |
| `LAYER_SELECTOR_UNKNOWN` | `WP_LAYER_SELECTOR_UNKNOWN` | 函数 selector 无法可靠分析；检查目标支持和受影响规则 |
| `LAYER_DESCRIPTOR_ORDER` | 无旧前缀 | 跨层 descriptor 定义同名或身份不明确；检查其注册语义 |
| `LAYER_WRAPPER_SEMANTICS` | 无旧前缀 | 编译器无法确认 wrapper 语义；检查包装规则，不能假定展平后语义不变 |

`onConflict: 'error'` 将这些兼容警告提升为构建错误，非法输入在 warning 模式也会失败。三个已有 `WP_LAYER_*` 前缀继续出现在 warning/error 文本中，程序读取的 `warning.code` 使用共享内核 `LAYER_*` 标识符。

内核 warning 附 `diagnostic` 对象，包含 `code`、`severity`、`message`、`suggestion`、`source`（可用时提供 `file`、`line`、`column`）。`related`、`layer`、`selector`、`property` 在适用时补充上下文。这些是发出消息的结构化字段，不是新增的 `IPostcssPluginOptions` 参数或适配器导出类型。可以同时读取 PostCSS 文本和原始诊断。下例使用 JavaScript：PostCSS 基础 `Warning` 类型未声明这些额外字段，TypeScript 调用方需先做类型收窄或局部断言再访问：

```js
import postcss from 'postcss'
import postcssImport from 'postcss-import'
import postcssPlugin from 'weapp-pandacss/postcss'

// sourceCss 为原入口文本，from 必须指向它的真实位置。
const result = await postcss([postcssImport(), postcssPlugin()]).process(sourceCss, {
  from: 'src/app.css',
  to: 'dist/app.wxss',
})

for (const warning of result.warnings()) {
  console.warn(warning.toString(), warning.code, warning.diagnostic)
}
```

共享内核报告的失败，包括严格诊断和非法输入，抛出 PostCSS `CssSyntaxError`，附 `code`、首个 error 级 `diagnostic`、完整 `diagnostics` 数组和 `cause` 原始编译错误。Adapter 配置、变量与 Panda polyfill 校验保留自己的既有错误，不要假定每个 adapter 错误都有内核诊断字段。共享内核错误兼容原冲突文本，并保留可用的源码位置。独立 layer 阶段先校验再提交 AST 变更，包括严格诊断失败；原子性仅针对**这个 layer 阶段**，前面的 adapter selector/命名转换可能已经改变 root。不要捕获错误后发布部分处理的 adapter root。

## Ordered 拒绝的输入

即使 `onConflict` 是 `'warning'`，下列错误也会阻止构建。

| 输入 | 处理方式 |
| --- | --- |
| `LAYER_IMPORT`：所有残留 `@import`，包括普通/带 layer/远程导入 | Adapter 前完整展开导入图，远程 CSS 放到本地或由前序阶段解析 |
| `LAYER_NESTING`：嵌套样式规则、`&` 或样式规则内的 layer | 在 adapter 前展开 nesting |
| `LAYER_REVERT`：`revert-layer` 值 | 换成明确值；适合 Web 时使用原生 layer |
| 已 polyfill 的 `:not(#\#)` selector | 保持 Panda `polyfill: false` 并重新生成原始 layer，或显式选择 legacy |
| `LAYER_NAME`：非法层名、无 block 的匿名 layer 声明、block 上多个层名 | 修正 layer 声明 |
| `LAYER_PREPROCESSOR`：残留的条件编译控制注释 | 适配前由预处理器消化 `#if` / `#else` / `#endif` 指令 |
| Descriptor at-rule 内的 layer、游离声明，或 layer/条件内的 import、namespace | 修正 CSS 结构 |

共享内核还使用 `LAYER_OPTIONS` 和 `LAYER_INPUT_STAGE` 表示编译器选项非法或输入被显式声明为已 polyfill，它们不是额外的适配器公开参数。保持文档中的 import/nesting/Panda 顺序，发生时检查原始诊断。

部分校验会在没有 `@layer` block 时执行，包括 import、nesting 和 `revert-layer`。`content: "revert-layer"` 这样的引号文本不会被视为关键字。

## 命名、变量与重复处理

Adapter 使用与 [runtime](/zh/api/runtime/) 相同的编码规则处理 class selector。手写 selector 保留原始名称，使用普通 CSS 转义。顶层 `/*! weapp-pandacss:portable-v1 */` 注释将命名标记保留到解析、序列化之后。重复处理带标记的产物不会再次编码；下一次 adapter 处理前不要删除标记。

小程序 custom property 声明、`var()` 引用和 `@property` 名称必须匹配 ASCII `--[A-Za-z0-9_-]+`。非法标识符抛出 `Unsupported mini-program CSS variable`。嵌套 `var()` fallback、已标记 Web CSS 再转小程序也会校验；引号字符串和 URL 中的文本不算变量引用。Adapter 不重命名变量，生成 token 由 Panda `hash.cssVar` 处理。

层顺序仅覆盖单个 PostCSS root。独立样式、组件样式和不同 processor 调用不共享 layer 注册表。相对层顺序需要跨输入保留时，先合并输入再适配，组件 style isolation 另行配置。
