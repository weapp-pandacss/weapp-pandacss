## Panda 生成 API

这些函数属于 **Panda CSS 2.1.2**，从项目生成的 `styled-system` 目录导入，不是 `weapp-pandacss` 的包导出。

| 参考 | API | 用途 |
| --- | --- | --- |
| [css 与 cx](/zh/api/styling/) | `css()`、`css.raw()`、`cx()` | 原子样式、样式组合与 class 列表 |
| [Recipes](/zh/api/recipes/) | `cva()`、`sva()`、named/slot recipes 与变体辅助函数 | 组件变体及多个部件 |
| [Tokens、patterns 与 styled](/zh/api/tokens-patterns/) | `token()`、`token.var()`、patterns、`styled` | 主题值、布局辅助函数与 React Web 组件 |

## 包入口

所有 JavaScript 入口都提供 ESM、CommonJS 和对应 TypeScript 声明。`IPostcssPluginOptions` 是类型导出。

| 入口 | 导出 |
| --- | --- |
| `weapp-pandacss` | `weappPanda`、`postcssPlugin`、`encodeClassName`、`encodeClassList`、`IPostcssPluginOptions` |
| `weapp-pandacss/panda` | `weappPanda` |
| `weapp-pandacss/postcss` | 默认导出的 `postcssPlugin` 工厂 |
| `@weapp-pandacss/runtime` | `encodeClassName`、`encodeClassList`、`createPortableRuntime` |
| `weapp-pandacss/runtime` | 同上三个 runtime 导出，兼容入口 |
| 两个包各自的 `/package.json` | 包元数据 |

页面代码使用 `@weapp-pandacss/runtime`，它不依赖 Panda、PostCSS、Babel 或 Node。主适配器包属于构建工具；独立 runtime 也适合单独发布的组件库。

```ts
import { weappPanda } from 'weapp-pandacss/panda'
import postcssPlugin from 'weapp-pandacss/postcss'
import type { IPostcssPluginOptions } from 'weapp-pandacss'
import { encodeClassName } from '@weapp-pandacss/runtime'

const panda = weappPanda()
const options: IPostcssPluginOptions = { target: 'weapp' }
const postcss = postcssPlugin(options)
const authored = encodeClassName('custom/active')
```

主包根入口不导出 `createPortableRuntime`，内部辅助函数也不是公共 API。v1 文件补丁 API、adapter 配置加载器、内部路径 wildcard 与两个 CLI 已删除，替代方式见[迁移指南](/zh/migration/)。

## 使用生成 API 前

注册 `weappPanda()` 和 PostCSS adapter，执行 `panda codegen`，并导入生成的全局 CSS。runtime 与 CSS 必须来自相同配置。接入步骤见 [Panda 配置](/zh/panda/)和 [PostCSS 配置](/zh/postcss/)。

Panda 输出已经编码，只有原始手写名称需要编码一次。适配器调整命名及 CSS 产物，不会在运行时生成 CSS、让任意动态样式可被提取，或补齐目标平台缺失的 CSS 能力。生成 class 没有对应样式时，按[排障指南](/zh/troubleshooting/)检查。
