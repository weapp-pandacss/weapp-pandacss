**weapp-pandacss** connects Panda CSS **2.1.2** to mini-program builds. Use Panda's styles, recipes and tokens in Taro, Uni-app or Weapp Vite; keep the same class naming on Web/H5.

## From a style to WXSS

The Panda plugin adapts generated JavaScript. The PostCSS plugin adapts the matching stylesheet. Both sides use the same class-name encoding.

<BuildFlow>
  <FlowStep icon="code" title="Author a style">
    TypeScript styles with `css()`.
  </FlowStep>
  <FlowStep icon="tag" title="Generate a portable class">
    `c_#0f766e` becomes `c__wp_23_0f766e`.
  </FlowStep>
  <FlowStep icon="file-cog" title="Match the WXSS selector">
    PostCSS emits `.c__wp_23_0f766e`.
  </FlowStep>
</BuildFlow>

### 1. Author a style

~~~ts
import { css } from '../styled-system/css'

export const badgeClass = css({ color: '#0f766e' })
~~~

### 2. Panda generates a portable class

~~~text
Panda class:       c_#0f766e
Mini-program/Web:  c__wp_23_0f766e
~~~

Assign `badgeClass` to `className` in Taro React, or to `:class` in Vue/Wevu. It already contains the portable class; use it directly.

### 3. PostCSS produces the matching selector

~~~css
.c__wp_23_0f766e {
  color: #0f766e;
}
~~~

The shown class and declaration are checked against real Panda codegen and CSS extraction. The complete stylesheet also contains Panda's other configured layers and the adapter's processing marker.

## Choose the right build target

| Concern | Mini-program | Web/H5 |
| --- | --- | --- |
| Panda generation plugin | `weappPanda()` | `weappPanda()` |
| PostCSS target | `'weapp'` (default) | `'web'` |
| Class naming | Shared portable encoding | Shared portable encoding |
| Cascade layers | Compile layer order for WXSS | Retain native layers |
| Selector compatibility | Limited platform transformations | Retain native selectors |

<Aside title="Panda configuration" icon="file-cog">
  Set `polyfill: false` in Panda so the adapter receives the original layers. See [PostCSS behavior](/postcss/) for conflicts and selector limits. The adapter handles naming and selected CSS transformations; platform CSS support still matters.
</Aside>

## Compatibility and migration

The adapter requires Panda **2.1.2** and JavaScript runtime artifacts (`.js` or `.mjs`). Its package entries support ESM, CommonJS and TypeScript declarations. Application code can import the dependency-free [standalone runtime](/api/runtime/).

The [framework matrix](/frameworks/) distinguishes verified build artifacts, browser interactions and mini-program runtime checks. For an existing v1 setup, follow the [2.0 migration guide](/migration/).
